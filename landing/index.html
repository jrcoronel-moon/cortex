The knowledge base
your AI can actually read

Cortex is a markdown workspace you run yourself. Write notes like you always have — then let Claude, Cursor or any MCP client read and write them, scoped to exactly what you choose to share.

What's inside

A notes app that understands itself

Everything is plain markdown on disk, in SQLite. No proprietary format, no lock-in — and no feature held back behind a plan.

✍️

Markdown workspace

Tabbed editor with YAML frontmatter, wikilinks, tables, syntax highlighting, Mermaid diagrams and editable draw.io diagrams embedded in the document.

🧠

3D knowledge graph

A WebGL graph of your notes where the AI-discovered connections — content similarity and shared vocabulary — sit alongside the links you wrote yourself.

🔍

Semantic search

Find notes by meaning, not keywords. Embeddings are computed locally with transformers.js, so nothing is sent to a third party.

💬

AI assistant

Chat grounded in your own notes, using your own API key. The key is encrypted at rest and never leaves your instance.

👥

Collaboration

Organizations, members and roles, per-folder sharing with view or edit access, and public read-only links for a single note.

📥

Import anything

Bring in markdown files and whole folders keeping their structure, or convert Word documents, web pages and PDFs into clean markdown.

Model Context Protocol

Your agents, your notes

Cortex ships an MCP server. Point any compatible client at your instance and it reads and writes as you — never beyond the spaces your account can reach.

  • Web clients connect over OAuth 2.1 + PKCE, with an explicit consent screen.
  • CLI and editor clients authenticate with a scoped API key.
  • Restrict any connection to specific folders.
  • Tools: list spaces, search, read, create and update notes.

Self-hosting

Runs on a small box

A Next.js app and a SQLite file. No external database, no queue, no vector service — embeddings and search run in-process.

  • Docker Compose stack with Caddy and automatic TLS.
  • Optional continuous backup to S3 with Litestream.
  • Bring your own SMTP for magic-link sign-in, or read the link from the log.
  • Your data stays on your hardware.
